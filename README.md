# Фреймворк веб-проектов: дизайн → фронтенд

Система работы над проектами (лендинги, корпсайты, e-commerce) в связке
с Claude Code. Идея: **правда живёт в артефактах, а не в макете** — смыслы
утверждаются дёшево (текстами) до дорогих этапов (макеты, вёрстка).

## Быстрый старт нового проекта

1. Создай папку проекта (например, `Сайт магазина игрушек`).
2. Скопируй в неё **содержимое** `_project-template/`.
3. Открой Claude Code в папке проекта и набери `/new-project` (или вставь
   стартовый промпт сессии «Триаж» из `framework/01-discovery.md`).
4. Дальше фреймворк ведёт сам: после каждой сессии Claude говорит, какая
   следующая; её промпт лежит в файле соответствующей фазы.

## Карта сессий

Одна сессия Claude Code = одна фаза (или её кусок). Промпт каждой сессии —
в её файле, копируется как есть.

| # | Сессия | Промпт в файле | Модель |
|---|---|---|---|
| 1 | Триаж | `framework/01-discovery.md` | Opus |
| 2 | Discovery | `framework/01-discovery.md` | Opus |
| 3 | Концепция | `framework/02-concept.md` | Opus |
| 4 | Прототип | `framework/03-design.md` | Sonnet |
| 5 | UI-кит | `framework/03-design.md` | Sonnet |
| 6 | Макеты | `framework/03-design.md` | Opus/Sonnet |
| 7 | Вёрстка | `framework/04-frontend.md` | Sonnet |
| 8 | Адаптив/анимации | `framework/04-frontend.md` | Sonnet |
| 9 | Релиз | `framework/05-release.md` | Sonnet |
| 10 | Ретро | `framework/05-release.md` | Opus |
| — | Контент-промптер (в любой момент) | `framework/content-gen.md` | Sonnet |

Какие сессии нужны конкретному проекту — решает Триаж (разметка фаз
в `PROJECT.md`). Ненужные пропускаются с записью причины в `decisions.md`.

## Файлы базы

| Файл | Что внутри |
|---|---|
| `framework/00-overview.md` | Карта процесса, философия, гейты, правило смыслов |
| `framework/01-discovery.md` … `05-release.md` | Фазы: шаги, чек-листы, промпты |
| `framework/stack.md` | Какой стек когда + фиксированные умолчания |
| `framework/models.md` | Какая модель для какой задачи, экономия токенов |
| `framework/content-gen.md` | Промпты для syntx.ai (фото/видео) |
| `framework/lessons.md` | Уроки проектов (пишет Ретро) |
| `_project-template/` | Копируется в каждый новый проект |

## Как фреймворк учится

1. После каждого проекта — сессия «Ретро» (~15 мин): уроки → `lessons.md`.
2. Новые проекты читают `lessons.md` на триаже — опыт наследуется.
3. **Правило двух повторов:** проблема повторилась в двух проектах →
   обязательная правка шаблонов/чек-листов/промптов + запись в `CHANGELOG.md`.
4. Править фреймворк можно и напрямую: попроси Claude в любой сессии
   («добавь во фреймворк…») — правка + строка в `CHANGELOG.md`.

## Скиллы Claude Code (работают в любой папке)

| Скилл | Что делает |
|---|---|
| `/new-project` | Создаёт проект из шаблона и проводит триаж |
| `/project-status` | Где мы, последние решения, следующая сессия с промптом |
| `/content-prompter` | Промпты для syntx.ai по контент-слотам |
| `/retro` | Ретро: уроки в lessons.md, правки фреймворка |
