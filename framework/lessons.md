# Уроки проектов

Сюда пишет сессия «Ретро» после каждого проекта. Новые проекты наследуют уроки
автоматически: CLAUDE.md шаблона велит читать этот файл на разборе.

**Правило двух повторов:** урок, повторившийся во втором проекте, обязан
превратиться в правку фреймворка (шаблон, чек-лист, промпт) + запись
в CHANGELOG.md. После правки урок помечается `[внесено во фреймворк]`.

## Формат записи

```
### ГГГГ-ММ-ДД — [проект]
- **Проблема:** что пошло не так / что буксовало.
- **Решение:** как решили в этом проекте.
- **Вывод:** что делать иначе в следующих проектах.
```
