# Сессия «Контент-промптер» (сквозная)

## Цель

Готовые к вставке промпты для генерации фото/видео/иллюстраций в syntx.ai —
под конкретные контент-слоты проекта, в едином стиле. Claude пишет промпты,
Евгений генерирует и кладёт результат в `assets/`.

## Когда вызывать

На любом этапе, где всплыл контент-слот без материала: чаще всего после
контент-карты (пакетная заготовка) и во время макетов (точечные дозаказы).

## Воркфлоу

1. Claude читает `content-map.md` (контент-слоты) и выбранное направление
   (палитра, настроение).
2. Для каждого слота пишет промпт по структуре ниже + рекомендует модель.
3. Промпты складываются в `assets/prompts.md` (слот → промпт → статус:
   ожидает / сгенерировано / в макете).
4. Евгений генерирует, отбирает, кладёт файлы в `assets/` с именем слота
   (например, `hero-main.webp`, `about-team-01.webp`).
5. Неудачные генерации: Евгений говорит, что не так → Claude правит промпт
   (итерация фиксируется в `prompts.md`, чтобы не повторять ошибки).

## Структура промпта для изображений

Промпты пишутся на английском (модели понимают его лучше), с переводом сути
на русский рядом. Обязательные части:

1. **Объект/сцена** — что изображено, максимально конкретно.
2. **Стиль** — фотореализм / 3D / флэт-иллюстрация / изометрия и т.д. —
   единый для всего проекта, из визуального направления.
3. **Свет и атмосфера** — soft daylight, golden hour, studio light…
4. **Палитра** — HEX-цвета проекта или их словесное описание.
5. **Композиция и кадр** — close-up / wide shot, ракурс, **где оставить пустое
   место под текст** (для героев и баннеров — критично).
6. **Формат** — соотношение сторон под слот макета (16:9, 4:5, 1:1…).
7. **Негатив** — чего не должно быть: text, watermark, logo, extra fingers,
   cluttered background (+ специфичное для слота).

Шаблон:

```
[объект/сцена], [стиль], [свет], [палитра], [композиция, место под текст],
aspect ratio [X:Y] --no text, watermark, logo, [негатив слота]
```

## Структура промпта для видео

1. Сцена и действие (одно простое движение — сложные ломаются).
2. Движение камеры: static / slow pan / slow zoom in — для веба лучше медленное.
3. Стиль и свет — те же, что у изображений проекта.
4. Длительность и формат: обычно 5–10 сек, зацикливаемое (seamless loop)
   для фоновых видео.

## Выбор модели в syntx.ai

Названия моделей в syntx.ai меняются — ориентир по классам:

| Тип контента | Класс модели | Ориентиры |
|---|---|---|
| Фотореалистичные сцены, люди | Флагманский фотореализм | FLUX, Imagen, Seedream |
| Иллюстрации, стилизация | Художественные | Midjourney, Recraft |
| Изображения с текстом (баннеры) | Модели с рендером текста | Ideogram, Recraft; либо текст класть в вёрстке |
| Иконки, простая графика | Не генерировать | SVG рисует Claude или берём иконочные наборы |
| Фоновые видео, оживление фото | Video-модели | Kling, Veo, Runway |

Правило: для серии изображений одного проекта — **одна модель и один базовый
стилевой хвост промпта**, иначе серия развалится по стилю.

## Консистентность серии

- Единый суффикс стиля (стиль + свет + палитра) — во всех промптах проекта,
  задаётся один раз в шапке `prompts.md`.
- Генерировать с запасом (2–4 варианта на слот), отбирать лучшее.
- Люди/персонажи: использовать референсные функции модели (image-to-image,
  character reference), иначе один «сотрудник» будет разным на каждом фото.

## Стартовый промпт

```
Прочитай CLAUDE.md, PROJECT.md, 00-docs/content-map.md и выбранное направление
в 01-concept/. Сессия «Контент-промптер» по framework/content-gen.md:
составь/обнови assets/prompts.md — для каждого незакрытого контент-слота
дай промпт по структуре (EN + суть на RU), рекомендуемый класс модели
в syntx.ai и формат. Задай единый стилевой суффикс проекта в шапке.
Нужны слоты: [все незакрытые / конкретные]
```
