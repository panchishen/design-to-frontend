# Новый проект по фреймворку

База фреймворка (только чтение): `${CLAUDE_PLUGIN_ROOT}`.

## Шаги

1. Первым делом спроси: «Нужна короткая памятка, как работать с Claude в этом
   фреймворке?» Да → выведи содержимое `${CLAUDE_SKILL_DIR}/memo.md` как есть,
   без пересказа и сокращений, и добавь: памятка есть и в README фреймворка.
   Нет → сразу дальше.
2. Спроси название проекта (если не сказано) и где создать папку. По умолчанию —
   текущая папка сессии: пустая → проект создаётся в ней, иначе — подпапка
   с названием проекта.
3. Скопируй СОДЕРЖИМОЕ `${CLAUDE_PLUGIN_ROOT}/_project-template/` в папку проекта.
   В `PROJECT.md` заполни название.
4. Спроси тип: новый сайт с нуля или лендинг на шаблоне (Dental AI).
   Лендинг на шаблоне → в PROJECT.md впиши «Трек: лендинг на шаблоне», замени
   таблицу фаз на таблицу из `${CLAUDE_PLUGIN_ROOT}/framework/landing-track.md`,
   выполни фазу 0 «Старт» по этому файлу и дальше работай через `/landing-next`.
   Шаги 5–6 не выполняй.
5. Прочитай `${CLAUDE_PLUGIN_ROOT}/framework/01-discovery.md` (раздел «Разбор
   проекта») и `${CLAUDE_PLUGIN_ROOT}/framework/lessons.md`. Проведи разбор строго
   по файлу фазы: вопросы 2–5 по одному (тип уже известен), затем разметка фаз
   в PROJECT.md, стек по `${CLAUDE_PLUGIN_ROOT}/framework/stack.md`, допущения
   в `00-docs/decisions.md`.
6. Скажи, какая фаза следующая и как её запустить: «Открой новую сессию в папке
   проекта и напиши `/next-phase`».

Если проект создан не в папке текущей сессии — напомни, что следующие сессии
открываются в папке проекта.

Общение — на русском, просто, без жаргона: пользователь может впервые работать
с Claude. Роли: Claude делает максимум, дизайнер решает.
