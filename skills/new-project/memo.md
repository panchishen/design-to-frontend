## Памятка: работа с Claude по фреймворку

**1. Открыть сессию в папке проекта.** Приложение Claude → вкладка **Code** →
новая сессия → выбрать папку проекта. Все сессии проекта открываются в его
папке: Claude читает `PROJECT.md` и знает, где остановились.

**2. Запускать фазы.** Одна фаза = одна новая сессия.

| Что | Команда |
|---|---|
| Новый проект | `/new-project` |
| Следующая фаза (сайт с нуля) | `/next-phase` |
| Следующая фаза (лендинг на шаблоне) | `/landing-next` |
| Где мы и что дальше | `/project-status` |
| Промпты для картинок/видео (syntx.ai) | `/content-prompter` |
| Итоги после сдачи проекта | `/retro` |

В конце фазы Claude сам предлагает плашку «запустить следующую фазу» — нажми её.
Команда не находится → набери `/` и выбери её из списка (полное имя —
`/design-to-frontend:next-phase` и т. п.).

**3. Режим запуска сессии.**

| Режим | Когда |
|---|---|
| **Start locally** | Почти всегда. |
| **Start with worktree** | Только если несколько сессий одновременно правят сайт. |
| Send to cloud / Fix in this session | Не использовать. |

Параллельно — только разные блоки или файлы; закончил → «слей в main и запушь»,
сливать по очереди. Правки одного блока — в одной сессии, пакетом.

**4. Поправил UI-кит в Figma, а сайт уже свёрстан.** Одна сессия
«Правка после вёрстки»: `/next-phase` → «правка после вёрстки», назови, что
изменилось (компоненты, токены, ссылка на фрейм). Claude обновит код и проверит
адаптив.

**5. Где файлы.** `PROJECT.md` — паспорт и статусы фаз; `00-docs/` — бриф,
контент-карта, решения (`decisions.md`); `01-concept/`, `02-design/` — концепция
и UI-кит; `03-code/` или `Лендинг/` — сайт; `assets/` — картинки, видео, промпты.

**6. Если что-то пошло не так.**
- Claude «забыл», что делали, → `/project-status`.
- Ответ ушёл не туда → **Esc**, объясни иначе. Откатить правки — попроси
  «верни как было».
- Сессия стала длинной и путаной → закрой, открой новую в папке проекта и
  продолжи той же командой фазы.
- Команд нет в списке → запусти «Установить фреймворк.cmd» ещё раз и
  перезапусти Claude.
- Не помогло — напиши владельцу фреймворка: что делал и скрин ошибки.
