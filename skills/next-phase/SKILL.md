# Следующая фаза полного цикла

База фреймворка (только чтение): `${CLAUDE_PLUGIN_ROOT}`. Пути `framework/…`
в файлах фреймворка и в `CLAUDE.md` проекта — относительно неё.

## Шаги

1. Прочитай `PROJECT.md` и `CLAUDE.md` в текущей папке. Нет `PROJECT.md` → скажи,
   что сессия открыта не в папке проекта, и предложи `/new-project`.
   Трек «лендинг на шаблоне» → переключись на `/landing-next`.
2. Фаза для работы: названная пользователем, иначе первая по порядку таблицы
   со статусом не «готово» и не «пропущена».
3. Файл фазы в `${CLAUDE_PLUGIN_ROOT}/framework/`: Разбор проекта, Исследование →
   `01-discovery.md`; Концепция → `02-concept.md`; Прототип, UI-кит, Макеты →
   `03-design.md`; Вёрстка, Адаптив/анимации, Правка после вёрстки →
   `04-frontend.md`; Релиз → `05-release.md`; Ретро → скилл `retro`.
   Читай только нужный раздел; на разборе — ещё `lessons.md`, при выборе
   стека — `stack.md`.
4. Выполни «Стартовый промпт» этой сессии из файла фазы как задание (вставлять
   его пользователю не нужно; данные, которые промпт просит вставить, — спроси).
   Поставь фазе статус «в работе», коротко скажи, что будет сделано.
   Вопросы — по одному. Если модель сессии не совпадает с таблицей
   `framework/models.md` — одной строкой подскажи, какую выбрать.
5. Решения и допущения — в `00-docs/decisions.md`.
6. Завершение: статус «готово» в `PROJECT.md`, итог в 2–3 строки, затем плашка
   на следующую фазу через `spawn_task` (title «<Проект>: <фаза>», prompt
   `/next-phase`, cwd — папка проекта). Если инструмент недоступен — скажи:
   «Открой новую сессию в папке проекта и напиши /next-phase».

Общение — на русском, кратко. Роли: Claude делает максимум, дизайнер решает.
