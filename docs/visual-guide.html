Экономия токенов

  • Состояние в файлах — чат закрывается без потерь
  • Сессия = фаза — без чатов-долгожителей
  • Точечный контекст — конкретные файлы, не «весь проект»
  • Правки пакетом — списком 5–10, не по одной
  • План отдельно от исполнения — Opus планирует, Sonnet делает

Быстрый старт

  • Создай папку проекта, скопируй содержимое _project-template/
  • Открой Claude Code в ней → скилл /new-project (или промпт Триажа)
  • Дальше: /project-status — где мы и что дальше
  • /content-prompter — промпты для syntx.ai
  • После сдачи: /retro — уроки во фреймворк
База фреймворка: Работа\Фреймворк · подробности каждой фазы — в framework/*.md, промпты сессий внутри.
